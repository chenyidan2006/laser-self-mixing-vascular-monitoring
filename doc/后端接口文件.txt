健康监测系统后端接口文档

基础URL:http://192.144.185.64:3000/api
所有接口返回JSON格式,编码UTF-8.
当前版本未实现身份认证,请求需携带设备ID参数(deviceId),默认设备ID为ESP32_001.

数据上传接口(POST /upload)
用于模拟4G模块上传脉搏波原始数据.

请求头:Content-Type: application/json

请求体参数:

deviceId : string 可选 设备ID,默认ESP32_001

timestamp : string 可选 ISO 8601时间戳,如2025-02-26T10:30:00Z,默认当前时间

voltage_values : array[number] 必填 脉搏波电压值数组,长度建议100~10000,单位V

sampling_rate : number 可选 采样率,单位Hz,默认125

duration : number 可选 数据时长,单位秒,默认根据数据长度计算

metadata : object 可选 附加元数据,如设备型号等

rawDataId : number 可选 原始数据ID(用于关联已有数据,一般不用)

bypassPython : boolean 可选 是否跳过Python算法处理(测试用),默认false

请求示例:
{
"deviceId": "ESP32_001",
"timestamp": "2025-02-26T10:30:00Z",
"voltage_values": [1.23, 1.45, 1.67, ...],
"sampling_rate": 125,
"duration": 1,
"metadata": { "model": "V1.0" }
}

成功响应(200):
{
"success": true,
"timestamp": "2025-02-26T10:30:00Z",
"heart_rate": 72,
"systolic_bp": 118,
"diastolic_bp": 78,
"spo2": 97,
"algorithm": "python_full",
"confidence": 0.85,
"raw_data_id": 12345,
"processed_id": 67890,
"processing_time_ms": 150,
"python_execution_time": 120,
"scores": {
"overall_balance": 85,
"vital_signs": 82,
"activity_level": 78,
"relaxation_state": 90,
"heart_rate_score": 85,
"blood_pressure_score": 88,
"spo2_score": 95
}
}

错误响应(4xx/5xx):
{
"success": false,
"message": "错误描述",
"request_id": "req_..."
}

数据查询接口

2.1 GET /data/deviceStatus
获取设备当前在线状态及今日记录数.
请求参数(Query):
- deviceId : string 可选 设备ID,默认ESP32_001

成功响应:
{
  "errcode": 0,
  "msg": "获取设备状态成功",
  "data": {
    "deviceId": "ESP32_001",
    "lastUpdate": "2025-02-26T10:29:00Z",
    "dataDelay": 1,
    "isConnected": true,
    "todayRecords": 128,
    "todayStatus": "active"
  }
}
字段说明:
- lastUpdate   : 最新一条数据的时间戳
- dataDelay    : 距离现在的时间差(分钟),若null表示无数据
- isConnected  : 是否在线(dataDelay < 5分钟视为在线)
- todayRecords : 今日已处理数据条数
- todayStatus  : active 或 inactive

2.2 GET /data/realtime
获取最近几分钟的实时数据(用于前端绘制趋势图或显示最新值).
请求参数:
- deviceId : string 可选 设备ID,默认ESP32_001
- minutes  : number 可选 取最近多少分钟的数据,默认10

成功响应:
{
  "errcode": 0,
  "msg": "获取实时数据成功",
  "data": {
    "heart_rate": [72, 74, 73, ...],
    "systolic_bp": [118, 119, 117, ...],
    "diastolic_bp": [78, 79, 77, ...],
    "spo2": [97, 98, 97, ...],
    "timestamps": ["2025-02-26T10:28:00Z", "2025-02-26T10:28:08Z", ...]
  },
  "lastUpdate": "2025-02-26T10:30:00Z"
}
所有数组长度相同,按时间升序排列.若该时间段无数据,数组为空.

2.3 GET /data/dailySummary
获取指定日期的每日汇总数据.

请求参数:
- deviceId : string 可选 设备ID,默认ESP32_001
- date     : string 必填 日期,格式YYYY-MM-DD

成功响应(有数据时):
{
  "errcode": 0,
  "msg": "获取数据成功",
  "data": {
    "date": "2025-02-26",
    "overallBalance": 85,
    "vitalSigns": 82,
    "activityLevel": 78,
    "relaxationState": 90,
    "avgHeartRate": 72.5,
    "avgSystolic": 118.3,
    "avgDiastolic": 77.8,
    "avgSpo2": 97.2,
    "bpHistory": {
      "systolic": [115, 118, 122, ...],
      "diastolic": [75, 78, 80, ...]
    },
    "heartRateHistory": [68, 72, 75, ...],
    "spo2History": [97, 98, 98, ...],
    "totalRecords": 128,
    "lastUpdate": "2025-02-26T10:30:00Z"
  }
}
若无数据,data返回一个空结构(所有值为null或空数组).

2.4 GET /data/availableDates
获取设备有数据的日期列表(用于日期选择器).

请求参数:
- deviceId : string 可选 设备ID,默认ESP32_001
- limit    : number 可选 返回最近多少天的日期,默认30

成功响应:
{
  "errcode": 0,
  "msg": "获取日期列表成功",
  "dates": ["2025-02-26", "2025-02-25", "2025-02-24"]
}

2.5 GET /data/hourlyRange
获取指定日期每小时的极值(用于圆柱图).

请求参数:
- deviceId : string 可选 设备ID,默认ESP32_001
- date     : string 必填 日期,格式YYYY-MM-DD

成功响应:
{
  "errcode": 0,
  "msg": "获取每小时极值成功",
  "data": [
    {
      "hour": 0,
      "heart_rate": { "min": 62, "max": 75 },
      "systolic_bp": { "min": 110, "max": 122 },
      "diastolic_bp": { "min": 70, "max": 80 },
      "spo2": { "min": 96, "max": 99 },
      "count": 12
    },
    ...
  ]
}
每小时一个对象,hour取值范围0~23.若该小时无数据,min和max为null,count为0.

CSV文件接口
目前从服务器文件系统中读取CSV文件,后续可能改为从数据库读取,接口保持不变.

3.1 GET /csv/files
获取所有CSV文件名列表(按名称自然排序).

成功响应:
["001.csv", "002.csv", "003.csv"]

3.2 GET /csv/data
获取指定CSV文件的分页数据.

请求参数:
- file  : string 必填 文件名,如001.csv
- page  : number 可选 页码,默认1
- limit : number 可选 每页条数,默认100

成功响应:
{
  "file": "001.csv",
  "total": 1250,
  "page": 1,
  "limit": 100,
  "data": [
    { "timestamp": "2025-02-26T10:00:00Z", "heart_rate": "72", ... },
    ...
  ]
}
data中每条记录的字段由CSV文件的列决定.

数据库表结构(参考)

processed_health_data(处理后数据)

id : bigint 主键

device_id : varchar(50) 设备ID

timestamp : datetime 数据时间戳

date : date 日期(冗余,方便查询)

hour : tinyint 小时

minute : tinyint 分钟

second : tinyint 秒

heart_rate : smallint 心率

systolic_bp : smallint 收缩压

diastolic_bp : smallint 舒张压

spo2 : tinyint 血氧

algorithm_used : varchar(50) 算法名称

confidence_score : decimal(3,2) 置信度

raw_data_id : bigint 关联原始数据ID

daily_summary(每日汇总)

id : bigint 主键

device_id : varchar(50) 设备ID

date : date 日期

avg_heart_rate : decimal(5,1) 平均心率

avg_systolic_bp : decimal(5,1) 平均收缩压

avg_diastolic_bp : decimal(5,1) 平均舒张压

avg_spo2 : decimal(4,1) 平均血氧

min_heart_rate : smallint 最低心率

max_heart_rate : smallint 最高心率

min_systolic_bp : smallint 最低收缩压

max_systolic_bp : smallint 最高收缩压

min_diastolic_bp : smallint 最低舒张压

max_diastolic_bp : smallint 最高舒张压

min_spo2 : tinyint 最低血氧

max_spo2 : tinyint 最高血氧

overall_balance : tinyint 总体平衡分

vital_signs_score : tinyint 体征状态分

activity_level_score : tinyint 活动水平分

relaxation_state_score : tinyint 放松状态分

hourly_data : json 每小时统计数据(包含平均值,计数等)

total_records : int 当日记录总数

错误码说明
所有接口均可能返回以下格式的错误:
{
"errcode": 400,
"msg": "错误描述"
}
常见错误码:

400 : 请求参数错误(缺少必填项,格式错误等)

404 : 资源不存在(如文件或数据未找到)

500 : 服务器内部错误(数据库连接失败,算法异常等)
