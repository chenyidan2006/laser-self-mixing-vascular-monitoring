# 硬件上电与联调清单

本清单按“先电源、再单板、后链路、最后激光”的顺序执行。不要第一次上电就同时连接激光、模拟前端、STM32、ESP32 和服务器。

## 1. 断电检查

- [ ] 确认板卡版本，避免混用 `AIA` 与 2026-02-06 Altium 文件。
- [ ] 万用表检查电源与 GND 是否短路。
- [ ] 确认所有板共地，UART 为 3.3 V TTL。
- [ ] 核对 STM32 PA9 → ESP32 GPIO18、STM32 PA10 ← ESP32 GPIO17。
- [ ] 核对 ADS8688 SPI：PA4 CS、PA5 SCK、PA6 MISO、PA7 MOSI、PA8 RST。
- [ ] 确认激光 MOS 上电默认关闭；测试阶段先断开激光负载。
- [ ] ESP32 GPIO5 按键需要外部约 1 kΩ 上拉到 3.3 V，按下接地。

## 2. 电源板与静态电压

1. 使用限流电源，小电流限值起步。
2. 不插 MCU/激光负载，先测各路电源输出。
3. 记录 5 V、3.3 V、模拟前端和激光供电的实际电压与静态电流。
4. 任何电压反向、明显过流或芯片升温都立即断电。

## 3. STM32 单板验证

1. 用 ST-Link 下载工程，确认 MCU 可连接且无读写保护问题。
2. 示波器/逻辑分析仪观察 PA5，确认采样时有约 5.25 MHz SPI 时钟。
3. 检查 PA4 片选与 PA8 复位时序。
4. 观察 PA9 UART，配置解码为 1,152,000 baud、8N1。
5. 理论上每 50 ms 出现一个 4,000-byte 块，共 160 块。
6. 检查 TIM2 中断是否在约 8 秒后停止。

注意：本 STM32 快照上电后自动采样，不等待 `A5 5A 01`。

## 4. ESP32 单板验证

1. 在固件本机副本填写 Wi-Fi 和服务器地址，不提交密码。
2. 选择带 PSRAM 的 ESP32-S3 板型并烧录。
3. 串口监视器设为 115200 baud。
4. 启动日志应显示 PSRAM 容量、约 704 KiB 帧槽分配成功和 Wi-Fi IP。
5. 不接 STM32 时按下按钮，应经历琥珀色预热、发送启动命令，随后因 2 秒内无数据转红并关闭激光控制。

## 5. STM32 ↔ ESP32 联调

当前两份固件启动语义不一致，先选择一种方案：

- **推荐**：给 STM32 增加 `A5 5A 01` 命令解析，收到后才开始一次 8 秒采集；
- **临时验证**：用复位/上电让 STM32开始发送，同时让 ESP32 已进入接收状态，但这种方式帧边界不可靠，不应作为正式方案。

联调时检查：

- [ ] ESP32 日志出现 `STM32 first payload byte received`；
- [ ] 一帧负载正好 640,000 bytes；
- [ ] 没有 `frame exceeded`、PSRAM 分配失败或 UART 首帧超时；
- [ ] 160 个 4,000-byte 块连续，无缺块/重复块；
- [ ] 抓取前 96 字节诊断样本，排除全 `00`、全 `FF` 或固定计数测试数据。

## 6. 网络与服务器验证

1. 先启动 `raw-receiver`，确认监听 `3000`。
2. ESP32 的 `SERVER_HOST` 必须是设备能访问的服务器 IP/域名，不能填 `127.0.0.1`。
3. `X-Device-Id` 应与 App 绑定设备号一致。
4. 成功时 ESP32 收到 HTTP 2xx，服务器产生 `.bin` 和元数据文件。
5. 检查服务器日志是否完成帧校验、算法执行及向后端 `3002` 写入。

## 7. 最后连接激光和人体测量

- [ ] 先确认 GPIO47/MOS 的高低电平和实际开关方向。
- [ ] 确认 15 秒自动关闭有效，异常复位时激光默认关闭。
- [ ] 遵守激光器安全等级要求，避免眼睛直视或镜面反射。
- [ ] 先用非人体测试目标验证光路和信号幅度。
- [ ] 确认 ADS8688 输入未超过配置量程，再进行人体实验。
- [ ] 人体数据采集需遵守知情同意、隐私和科研伦理要求。

## 常见现象

| 现象 | 优先检查 |
| --- | --- |
| ESP32 一按键就提示无 STM32 帧 | 两份固件启动命令不匹配、UART 交叉接线、共地、波特率 |
| 只收到约 1 秒或长度不固定 | ESP32 未在 STM32发送前进入接收、UART 丢块、DMA 被覆盖 |
| 数据全是递增数字 | `ads8688_start_sample()` 初始化测试数据尚未被真实采样覆盖，或采样中断未运行 |
| 数据全 0/全 `FFFF` | SPI MISO/CS/RST、ADS8688 电源/参考、模拟输入、SPI 模式 |
| 服务器收到但算法失败 | 帧头参数、640,000-byte 长度、`#END`、通道拆分和模型输入点数 |
| App 看不到结果 | `X-Device-Id`、后端 3002、设备绑定和数据库记录 |

联调完成后应保存逻辑分析仪截图、一次完整帧的 SHA-256、固件 commit 和板卡版本号，形成可复现的验证记录。
