# 算法状态、已解决冲突与剩余问题

## 已经确认

| 事项 | 结论 |
| --- | --- |
| 测量原理 | 激光自混合干涉（SMI/LSMI），不是 PPG |
| ADC 与主控 | ADS8688 与 STM32 位于自制四层 PCB 上 |
| ESP32 | 购买的 ESP32-S3-N16R8 开发/核心板，通过飞线连接 |
| 激光供电 | 老师设计激光头；团队另加 MOS 管作电源开关，并飞线按钮控制定时通电 |
| 物理通道 | 当前只采单通道 |
| ADC 采样率 | 40 kHz |
| 模型采样率 | 20 kHz |
| UART | 1,152,000 baud，仅是通信速率 |
| 帧头 `ch=2` | 历史兼容硬编码，不能据此拆成两路 |
| STM32 数据布局 | 每次中断读取一次通道，连续 16 位样本；不是双通道交错 |
