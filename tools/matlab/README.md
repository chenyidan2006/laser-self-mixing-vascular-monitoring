# MATLAB 原始帧诊断工具

本目录归档两个用于检查 ADS8688 原始帧的 MATLAB 脚本。它们是开发与诊断工具，不是服务器现役血压推理算法，也不会替代 `prodict_algorithm_infuwuqi/` 中的 MATLAB Runtime 可执行程序。

## 文件关系

| 文件 | 作用 | 是否改变数据 |
| --- | --- | --- |
| `bin_convert_txt.m` | 把服务器保存的二进制 `.bin` 原样转换为每字节两位十六进制的 `.txt` | 不改变字节内容，只改变可读表示形式 |
| `frame_fix_convert_plot.m` | 解析帧头/帧尾、恢复 `uint16`、换算电压、选择 A/B 块、滤波并绘图 | 分析时会丢弃已知无效首样本；只有 `saveTxt=true` 才另存结果 |

推荐使用 MATLAB R2016b 或更高版本，因为脚本末尾包含局部函数。滤波器由脚本自行实现，不要求 Signal Processing Toolbox。

## 最短使用步骤

### 直接分析已有十六进制 TXT

1. 打开 `frame_fix_convert_plot.m`。
2. 把 `filePath` 改成待分析 `.txt` 的完整路径。
3. 保持 `autoFrame=true`，先保持 `blockSel=0`。
4. 运行脚本，先阅读命令行输出，再看两个主图窗口。
5. 将 `blockSel` 分别改成 `1` 和 `2` 重跑，比较 A/B 两组块。

### 分析服务器保存的 BIN

1. 打开 `bin_convert_txt.m`，修改 `inputFile`。
2. 运行后会在原目录生成同名 `.txt`。
3. 将生成文件填入 `frame_fix_convert_plot.m` 的 `filePath`，再运行分析。

`.bin → .txt` 只是为了便于 MATLAB 脚本读取和人工检查，会使文件体积明显变大。它不是算法必须步骤，服务器仍应保存原始 `.bin`。

## 运行前最重要的参数

| 参数 | 默认值 | 含义 |
| --- | ---: | --- |
| `autoFrame` | `true` | 自动识别帧头、无效首样本和字节序，通常不要关闭 |
| `blockSel` | `0` | 现役单通道必须使用 `0` 看完整连续流；`1/2` 仅用于来源明确的旧版块交替文件或诊断对比 |
| `filtMode` | `bandpass` | 默认进行零相位带通；可设为 `none` 查看不滤波结果 |
| `bpLow` | `100 Hz` | 默认高通截止频率，用于压制直流、50 Hz 和约 10 Hz 块交替成分 |
| `bpHigh` | `0.45 × Fs` | 低通截止频率，限制接近奈奎斯特频率的高频噪声 |
| `zoomPts` | `3200` | 局部波形显示点数；完整流 40 kHz 下对应 80 ms |
| `saveTxt` | `false` | 是否另存换算后的原始电压和滤波后电压 |

学长已确认现役硬件只采单通道，采样率为 40 kHz；模型用 20 kHz 训练。帧头 `ch=2` 是遗留字段。现役文件应保持 `blockSel=0`，随后使用与训练流程一致的方法把连续 40 kHz 流降到 20 kHz。`blockSel=1/2` 会保留一个 2,000 点块、丢掉下一个 2,000 点块，它不是均匀降采样，只适用于确实由旧版块交替固件产生的文件。

默认 `bpLow=100 Hz` 适合观察高频 SMI 细节、工频和块切换伪迹，不适合直接保留心率约 1 Hz 等低频脉搏波成分。这个滤波结果用于诊断，不是血压模型输入。若要研究低频生理波形，应降低 `bpLow`、选用其他滤波方案，或先设 `filtMode='none'` 对照。

## 8 个主图分别是什么

脚本正常会打开两个主窗口，每个窗口包含 4 个子图，即通常所说的“8 个图”。前四幅回答“数据整体长什么样”，后四幅回答“滤波到底做了什么”。

### 窗口一：滤波后数据总览

#### 1. 全段波形（滤波后）

- 横轴：时间；纵轴：扣除直流并滤波后的交流电压，单位 mV。
- 用途：查看整段记录是否连续、是否存在突发尖峰、饱和、明显分段或幅度随时间漂移。
- 异常提示：长时间贴近固定值可能是无信号；孤立大尖峰可能是接触、复位或帧错位；周期性台阶可能与 A/B 块切换有关。

这张图已经滤掉低频，不能用它判断原始直流电平，也不能直接当作血压曲线。

#### 2. 局部放大

- 横轴：前若干点对应的毫秒；纵轴：滤波后的交流电压，单位 mV。
- 默认显示前 3,200 点：完整流 40 kHz 下约 80 ms，单组 20 kHz 下约 160 ms。
- 用途：观察单个振荡周期、尖峰形状、振铃、量化台阶和短时噪声；全段图压缩后看不清的细节在这里查看。

如果只在记录开头出现异常振铃，可能是滤波端点效应；脚本已用较长镜像延拓降低这种假象，但仍应与不滤波结果对照。

#### 3. 幅值分布直方图

- 横轴：滤波后交流电压，单位 mV；纵轴：落入该幅值区间的采样点数。
- 用途：查看噪声和信号幅值是否集中、是否偏斜、是否存在长尾或多峰。
- 异常提示：很窄的单峰可能表示信号过小；两侧出现硬边/大量堆积可能表示削顶；长尾通常对应尖峰或运动干扰。

它是采样幅值的统计分布，不是血压值分布，也不包含时间顺序。

#### 4. 全频段幅值谱对比

- 横轴：频率 Hz；纵轴：幅值 dBV。
- 灰线：滤波前；黑线：滤波后。
- 用途：查看主要频率成分、宽带噪声，以及滤波前后哪些频率被压低。
- 重点：观察 50 Hz 附近、低于 100 Hz 的区域和接近奈奎斯特频率的高频区域。

这张图展示的是数据频谱，不是滤波器理论曲线；理论曲线在第 7 图。

### 窗口二：带通滤波细节

只有实际启用了带通或陷波时才出现这个窗口。

#### 5. 去直流后时域对比

- 横轴：局部时间；纵轴：交流电压 mV。
- 灰线：只扣除均值、尚未滤波的原始信号；红线：滤波后信号。
- 用途：直观看滤波是否只是去掉缓慢漂移和工频，还是把有用波形也明显改变了。

红线与灰线差别过大不一定表示滤波“更好”，也可能是 `bpLow=100 Hz` 对目标信号过高。

#### 6. 低频段频谱对比

- 默认显示 0–500 Hz；灰线为滤波前，红线为滤波后。
- 图中的 50 Hz 竖线标出工频，`bpLow` 竖线标出默认 100 Hz 高通截止位置。
- 用途：专门检查直流漂移、约 10 Hz 块交替伪迹、50 Hz 工频及低次谐波是否被压制。

它比第 4 图更适合观察低频细节，因为横轴范围更窄。

#### 7. 滤波器幅频响应

- 横轴：频率 Hz；纵轴：滤波器增益 dB。
- 蓝线：滤波器单向经过一次的理论响应。
- 红色虚线：为实现零相位而前向、反向各滤一次后的总响应，幅度响应相当于平方，阻带衰减也更强。
- 用途：确认设计的通带、截止位置和阻带衰减是否符合预期。

这张图描述滤波器本身，不描述当前文件里实际有哪些频率。

#### 8. 被滤掉的成分

- 计算方式：`去直流的滤波前信号 - 滤波后信号`。
- 横轴：局部时间；纵轴：被移除部分的电压 mV。
- 用途：直接观察滤波器拿走了什么，通常包括慢漂移、50 Hz 工频、块交替造成的低频台阶，也可能包含真正有用的低频生理成分。

如果这张图呈现清晰、稳定且像真实脉搏的波形，说明截止频率可能设得过高，不能把被滤除部分简单当作噪声。

## 为什么有时还会多出第 9 个窗口

当 `autoFrame=true` 且脚本检测到需要跳过字节（例如开头的无效 `0xFFFF`）时，会额外打开“帧头处理对比”窗口：

- 左图使用自动识别出的正确跳字节数和字节序；
- 右图故意多错一字节并反转字节序，展示低字节错位后的结果。

它用于说明帧对齐为什么重要，不是第 8 个主分析指标。右图把“偏移错误”和“字节序错误”组合在一起，只用于快速诊断，不能据此分别量化两种错误的影响。

## 建议的实际检查顺序

1. 先用 `filtMode='none'`、`blockSel=0` 看现役单通道 40 kHz 原始全流，确认没有饱和、全零、大段缺失或 2,000 点边界跳变。
2. 只有分析来源不明的旧文件时，才用 `blockSel=1` 和 `2` 生成奇偶块对比；不要把这一步当成现役降采样。
3. 再启用默认带通，重点看第 5、6、8 图，确认滤波没有误删目标成分。
4. 保存运行时的帧头、命令行统计、8 个图和原始文件 SHA-256，和固件 commit 一起记录。

现役单通道、40→20 kHz 降采样、旧版块交替和 `ch=2` 遗留字段的完整解释见 [`../../prodict_algorithm_infuwuqi/FRAME_PROTOCOL.md`](../../prodict_algorithm_infuwuqi/FRAME_PROTOCOL.md)。
